# Week 4: Applied Machine Learning

This folder documents a five-day progression from framing a supervised learning problem to building and evaluating a deployable machine-learning capstone. The notebooks use the UCI Adult/Census Income dataset to explore how a reliable classification workflow is designed, measured, and improved.

## Learning roadmap

| Day | Focus | What you will practice |
| --- | --- | --- |
| [Day 1](./Day1/) | Problem framing and baselines | Define a prediction target and success metrics, explore data, create reproducible hold-out splits, and establish simple baselines. |
| [Day 2](./Day2/) | Preprocessing and supervised models | Build preprocessing/model pipelines, compare models with multiple metrics, and check interpretability. |
| [Day 3](./Day3/) | Feature engineering | Create and justify features that improve the representation of the prediction problem. |
| [Day 4](./Day4/) | Tuning and regularization | Build reproducible pipelines, search hyperparameters, and diagnose overfitting and underfitting. |
| [Day 5](./Day5/) | Classification capstone | Compare ensemble models, address class imbalance, interpret results, and prepare a model for inference and monitoring. |

## Skills covered

- Framing a measurable supervised-learning problem
- Exploratory analysis and reproducible train/test splits
- Baselines, preprocessing, and scikit-learn pipelines
- Feature engineering and model comparison
- Hyperparameter tuning, regularization, and error analysis
- Class-imbalance strategies and model interpretability
- Inference, monitoring, and communicating results

## Getting started

Open the notebooks in day order, starting with `Day1/week4_day1.ipynb`. Each day’s folder contains its notebook and related outputs or notes. Use a Python environment with Jupyter and the libraries imported by the notebooks.

## Repository hygiene

The accompanying `.gitignore` excludes local environments, caches, credentials, and runtime databases. Notebooks, documentation, charts, and model files are not blanket-ignored; review generated artifacts and dataset redistribution terms before publishing.
